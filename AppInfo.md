## Домашнее задание 4: Hilt + Room

Проект сделан поверх ДЗ №3: открытый API, список/поиск, экран деталей, Repository, ViewModel, coroutines, `viewModelScope`, Navigation Compose.

## Используемый API

TheMealDB: https://www.themealdb.com/api.php

- `GET /search.php?s={name}` - поиск рецептов по названию
- `GET /lookup.php?i={id}` - детали рецепта по id

## Что хранится в Room

Таблица: `favourite_meals`

Сценарий: Favourites. Пользователь добавляет рецепт в избранное, и запись сохраняется в Room. После полного перезапуска приложения избранные рецепты остаются доступными на экране "Избранное". Detail для избранного рецепта открывается из Room, включая название, категорию, страну, инструкцию, URL изображения и список ингредиентов.

## Как проверить

1. Найти рецепт через поиск.
2. Открыть detail и добавить рецепт в избранное.
3. Полностью закрыть приложение.
4. Выключить интернет.
5. Открыть приложение снова.
6. Перейти в "Избранное" и открыть сохранённый рецепт.
7. Рецепт, ингредиенты и инструкция остаются на месте, detail берётся из Room.
